apksig Go → WebAssembly

Pure-Go port of Android's apksig library, compiled to WASM. Verify and sign APKs locally — nothing leaves your browser.

Supports v1 (JAR), v2, v3, v3.1, v4 (.idsig). Source: github.

JavaScript API

Once apksig.wasm is loaded these globals are available:

// 1. Verify
const result = apksigVerify(uint8Array, { minSdk: 24, maxSdk: 35 });

// 2. Sign
const { signedApk, idsig } = apksigSign(apkBytes, keyPEM, certPEM, {
  v1: false,       // JAR signing (for Android < 7)
  v3: true,
  v31: false,      // v3.1 key rotation
  v4: false,       // .idsig file
  align: false,    // zipalign: 4-byte files, 16KiB page-align uncompressed .so
  v3MinSdk: 28,
  v31MinSdk: 33,
});

// 2b. Sign with a JKS or PKCS#12 keystore
const r = apksigSignKeystore(apkBytes, keystoreBytes, {
  storePass: "changeit",
  keyPass: "",     // optional, defaults to storePass
  alias: "",       // optional, defaults to first key entry
  v1: false, v3: true, v31: false, v4: false, align: false,
});

// 3. Verify v4
const v4Result = apksigVerifyV4(apkBytes, idsigBytes);

// 4. Generate key pair (returns { keyPEM, certPEM })
const { keyPEM, certPEM } = apksigGenerateKey({
  commonName: "Android Test",
  org: "Example Inc",
  country: "US",
  validityDays: 10950,
  keyType: "rsa",       // "rsa" | "ecdsa"
  rsaBits: 2048,
});
